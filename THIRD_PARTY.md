# Third-party components

## LibTIFF / tiff2pdf

This application invokes the `tiff2pdf` command-line tool from the LibTIFF distribution.

- Project: https://libtiff.gitlab.io/libtiff/
- License: LibTIFF license (see upstream distribution)

Bundled `tiff2pdf.exe` and DLLs in `vendor/` are not part of this repository’s source; obtain them from an official LibTIFF 4.7+ Windows build.
